# Sistema OmniChannel para Clínica Médica.
Projeto acadêmico desenvolvido como protótipo de um sistema de atendimento multicanal para uma clínica médica fictícia.

## Objetivo.
Simular uma central de atendimento integrada (WhatsApp, Instagram, Facebook e E-mail), permitindo a visualização e organização de mensagens de pacientes.

## Tecnologias utilizadas.
- HTML
- CSS
- JavaScript

## Funcionalidades

- Simulação de mensagens de diferentes canais
- Dashboard com métricas básicas
- Filtro de busca de mensagens
- Interface interativa com manipulação do DOM

## Contexto
Projeto desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, com foco em lógica de programação e desenvolvimento web básico.
